# Girl Survival Kit 💅

**Live demo:** https://shreyajainnx09.github.io/girlsurvivalkit/

## Description
A fun, personalized "what to carry" generator: pick your situation, duration, weather, and vibe, and it curates a tailored survival kit of items to bring along.

## Features
- Situation selector: Travel, College Day, Party/Night Out, Work/Internship, Date Night, Emergency Mode
- Duration filter: few hours, full day, or multiple days
- Weather filter: hot, cold, rainy, or mixed
- Vibe/aesthetic selector: Clean Girl, IT Girl, Chill, High Maintenance, Minimalist
- "Extra Prepared Mode" toggle that adds backup and just-in-case essentials
- Dark mode toggle

## Tech Stack (typical — adjust to match your actual repo)
- HTML5 / CSS3 / JavaScript
- Rule-based recommendation logic mapping situation + vibe + conditions to a curated item list

## Getting Started
```bash
git clone https://github.com/shreyajainnx09/girlsurvivalkit.git
cd girlsurvivalkit
python3 -m http.server 8000
```
Visit `http://localhost:8000`.

## Usage
1. Choose your situation (required).
2. Optionally set duration and weather.
3. Pick your vibe, and toggle "Extra Prepared Mode" if you want backup items.
4. Click "Generate My Kit" to get your personalized list.
